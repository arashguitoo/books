GitHub-Verbindung

Damit speichert die Verwaltung book.enc und keys.json selbst im Repo – kein Herunter- und Hochladen nötig. Einmalig einen Token anlegen:

  1. Auf github.com: Profilbild → Settings → ganz unten Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name z. B. „Buch-Codes“, Ablaufdatum nach Wunsch.
  3. Repository access: „Only select repositories“ → books.
  4. Permissions → Repository permissions → Contents: „Read and write“.
  5. „Generate token“ klicken, den Token kopieren und hier einfügen.

Der Token wird nur in diesem Browser gespeichert. Er erlaubt nur Zugriff auf das Repo „books“.

Ersteinrichtung – PDF verschlüsseln

Nur einmal pro Buch nötig. Die PDF wird hier im Browser verschlüsselt und verlässt dein Gerät nicht. Danach lädst du book.enc und keys.json ins Repo – niemals die unverschlüsselte PDF.

Das Passwort lässt sich nicht wiederherstellen. Ohne Passwort kannst du keine neuen Codes erzeugen – dann müsstest du die Einrichtung wiederholen (alte Codes würden ungültig).
